# Deepwell Media

**Turn expertise into influence.**

Marketing site for Deepwell Media, a B2B expertise media company that builds strategic conversations into original media, relationships and influence.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stack

- Next.js App Router
- React + TypeScript
- Native CSS design system
- Next Font

## Brand

Primary visual direction uses deep navy/charcoal, forest green, sage and warm off-white. The Deepwell wordmark is typography-led with only the final `l` accented to preserve legibility and avoid an initials-based `DW` identity.
